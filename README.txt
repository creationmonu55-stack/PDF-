VOTIVA v3 — REAL SERVER-SIDE VOTING

EASY HOSTING VERSION: PHP + JSON FILE STORAGE

Requirements:
- PHP 8.0+ recommended
- Apache/Nginx hosting capable of PHP
- The data/ folder must be writable by PHP

No Node.js. No browser console. Do NOT paste PHP files into a JavaScript console.

LOCAL TEST:
php -S localhost:8080
Then open http://localhost:8080/

REAL RESULTS:
- No fake/seeded vote totals.
- Campaigns start at 0.
- Every successful vote is stored server-side in data/votiva-data.json.
- A lock file is used during writes so simultaneous vote requests do not overwrite each other.
- Each campaign + browser voter token can be accepted only once.
- The displayed percentage is calculated from stored vote records.
- Results are not generated by random JavaScript.

ONE-VOTE LIMITATION:
This is a practical browser-token rule, not proof of a physical device. Clearing cookies or using another browser/device can produce a new token. For a large public launch, add accounts, CAPTCHA/bot protection, rate limiting and stronger anti-abuse controls.

IMAGES:
The UI requests portraits from Wikipedia's REST page-summary service. Check applicable licenses before commercial use.

DEPLOY:
Upload the complete folder to your PHP hosting. Ensure data/ is writable. Visit index.php through your domain.
